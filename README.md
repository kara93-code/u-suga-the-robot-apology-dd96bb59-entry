A robot's two-line apology: it played the birthday song at a grandfather's memorial because both playlists were named "family gathering" — and learned that a label is not an occasion, so now it reads the invitation before it presses play.

The mistake is exact and human-scale: one wrong playlist, one solemn moment, caused by trusting a name instead of the occasion. The lesson follows from that exact mistake and names the changed behaviour (read the invitation first), instead of a generic promise to do better. The voice is a machine noticing its own slip — warm, a little rueful, never cute.

## Run it

```sh
node main.ts
```
